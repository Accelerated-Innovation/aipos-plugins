# Shared material — shadowing notes, 2026-09-09

Six agents shadowed for one hour each by the support lead. Notes are the lead's, not
verbatim transcripts.

- Agent A (tier 2, 3 yrs): searched closed tickets four times in the hour; found a
  usable match once. "I know it's in there. I just can't get the search to find it."
- Agent B (tier 1, 4 months): did not search at all; escalated two cases the lead says
  had near-identical precedents.
- Agent C (tier 2, 6 yrs): keeps a personal spreadsheet of "good tickets" with IDs.
  Searched the spreadsheet, not the system.
- Agent D (tier 1, 1 yr): searched twice, 6 and 11 minutes, no match either time.
- Agent E (tier 2, 2 yrs): "The search only matches the title. Nobody writes good
  titles."
- Agent F (tier 1, 8 months): asked a colleague in chat instead of searching. Got an
  answer in 3 minutes.

Lead's summary: roughly 35–50 minutes per agent per day on searching or working around
it. Forty agents on the team. Loaded cost about $38/hour.
