# Epic: Build a document management system

**Key:** OPS-210
**Target release:** FY26 Q3
**Category:** Internal Operations
**Owner:** Marcus Vale

## Elevator pitch

We will build a centralized document management system with version control, full-text
search, and role-based permissions to replace the current shared drive.

## User problem(s)

We don't have a document management system. The shared drive has no version control and
no permissions model, and we need to migrate off it before the storage contract renews.
Users can't find documents.

## Alignment to business objectives

Supports operational excellence, digital transformation, cost reduction, employee
experience, and the FY26 modernization program.

## Success metrics

- Improved document findability
- Better version control
- Higher user satisfaction
- Reduced storage costs

## Evidence and insights

Everyone knows the shared drive is a mess. Several people have complained about it in the
ops channel. A competitor has a document portal.

## Initial scope / MVP

Full-text search, version history, role-based permissions, migration tooling, an approval
workflow, retention policies, an audit log, and a mobile app.

## Risks and mitigations

- Migration might be complex — we will monitor closely.
- Adoption could be slow — we will send an announcement.

## Non-functional requirements

The system should be fast and secure.
