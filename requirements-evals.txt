# Model-graded eval runner — SEPARATE from requirements-dev.txt on purpose.
#
# The deterministic gate (`python -m pytest tests -q`) must stay offline and
# key-free: both CI jobs run with no API key and no network at test time, and
# that is a property worth keeping. Installing the Anthropic SDK into that
# environment would invite a test that quietly bills the account.
#
#   python -m pip install -r requirements-evals.txt
#   python evals/run_evals.py --skill govkit-feature-create            # free
#   python evals/run_evals.py --skill govkit-feature-create --execute  # costs money
#
# REQUIRES PYTHON 3.10+. The deterministic suite runs on older interpreters;
# the Anthropic SDK does not, and pip's error for that is a wall of version
# numbers that does not say so.
#
# See evals/README.md.
anthropic>=1.0
