# AIPOS 1.0.0 candidate verification

**Status:** Local implementation; not published. Live routing and coaching
acceptance are pending an evaluation budget. This is not a release sign-off.

The candidate consolidates `aipos-p1` 0.1.1, `aipos-p2` 0.4.0, and `govkit` 0.17.0
into `aipos` 1.0.0 with eleven `aipos-*` skills. Existing `.govkit/` paths and
execution contracts remain unchanged. The local integration branch is
`codex/aipos-plugin-consolidation`; the [plan](plans/2026-09-19-aipos-plugin-consolidation.md#implementation-evidence)
records increments and their evidence.

The [rollout guide](rollout.md) describes fresh installation and removal of early
plugins. Verification results and remaining acceptance work are recorded below
before the release checkpoint.
